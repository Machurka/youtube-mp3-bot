# YouTube MP3 Bot

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

[🇬🇧 Read in English](README.md)

Telegram-бот на `python-telegram-bot` + `yt-dlp`: скачивает аудио с YouTube (MP3/WAV, на выбор битрейт), видео с TikTok, умеет искать ролики на YouTube прямо из чата и вести простую статистику для админа.

## Возможности

- **YouTube → MP3 / WAV.** Кидаешь ссылку — бот предлагает формат и битрейт (128/192/320 kbps).
- **Поиск по YouTube.** `/search запрос` — до 15 результатов с пагинацией, выбираешь ролик кнопкой.
- **TikTok.** Ссылка на TikTok скачивается видео в чат — с тремя независимыми методами на случай, если один из них заблокирован.
- **Ограничение длительности.** Настраиваемый лимит по минутам, чтобы не качать часовые видео по ошибке.
- **Статистика и модерация для админов.** `/stats` — сколько всего скачано и кем, `/clear N` — чистка последних N текстовых сообщений в чате (медиа и ссылки не трогает).
- **Устойчивость к сбоям.** Если основной способ скачивания не сработал — бот автоматически повторяет попытку, затем пробует альтернативный формат, а затем резервный внешний сервис.

## Требования

- Python 3.10+
- [ffmpeg](https://ffmpeg.org/download.html) — должен быть доступен в `PATH` (нужен для конвертации в MP3/WAV)
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- (опционально) [Deno](https://deno.com/) — современный yt-dlp использует его для обхода JS-защиты YouTube; без него часть форматов может быть недоступна

## Установка

```bash
git clone https://github.com/<твой-профиль>/youtube-mp3-bot.git
cd youtube-mp3-bot

python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и впиши свой токен:

```bash
cp .env.example .env
```

```env
BOT_TOKEN=твой_токен_от_botfather
ADMIN_IDS=твой_telegram_id
```

Запуск:

```bash
python main.py
```

На Windows можно просто запускать `start.bat`, на Linux/macOS — `./start.sh`.

## Куки (опционально)

Для приватных или возрастных видео YouTube может потребовать авторизацию. Экспортируй куки браузера (например, расширением [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)) в файл `cookies.txt` рядом с ботом — он подхватится автоматически. Без этого файла бот тоже работает, просто часть видео может быть недоступна.

**Не публикуй `cookies.txt` — это фактически ключ от твоего Google-аккаунта.** Файл уже в `.gitignore`.

## Если YouTube/Telegram у тебя ограничены

В `config.py` есть два независимых прокси:

- `TG_PROXY` — SOCKS5-прокси только для Telegram Bot API (например, SOCKS-порт локального VPN-клиента).
- `YOUTUBE_PROXY` — прокси только для трафика YouTube (yt-dlp). Оставь пустым, если используешь системный DPI-обходчик (например, [Zapret](https://github.com/bol-van/zapret), популярный в России) — тогда трафик YouTube уже обходит блокировки на уровне ОС, и yt-dlp отдельный прокси не нужен.

Оба задаются через `.env` (см. `.env.example`) и могут использоваться как вместе, так и по отдельности.

## Команды

| Команда | Описание |
|---|---|
| `/start` | приветствие и краткая инструкция |
| `/help` | справка по командам |
| `/search запрос` | поиск видео на YouTube (до 15 результатов) |
| `/stats` | статистика скачиваний (только для админов из `ADMIN_IDS`) |
| `/clear N` | удалить N последних текстовых сообщений, начиная с того, на которое отвечаешь (только для админов) |

Просто отправь ссылку на YouTube или TikTok — остальное бот сделает сам.

## Структура проекта

```
main.py        — точка входа, настройка логирования и хендлеров
handlers.py     — обработчики команд/сообщений/кнопок
downloader.py   — вся логика скачивания и конвертации YouTube-аудио
tiktok.py       — скачивание видео с TikTok (3 независимых метода)
startup.py      — учёт чатов, уведомление о запуске
config.py       — конфигурация (секреты — через .env)
```

## Известные ограничения

- Резервный внешний API для YouTube (используется, только если yt-dlp полностью не справился) — сторонний недокументированный сервис, может быть нестабилен сам по себе.
- YouTube регулярно меняет защиту от ботов — если скачивание массово перестало работать, в первую очередь попробуй `pip install -U yt-dlp`.
- Бот не проверяет права на контент — использование для скачивания чужих материалов остаётся на совести того, кто его запускает.
